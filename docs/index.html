2TDB

Source on GitHub API reference

2TDB is a bitemporal key-value store. Below is the memory a support agent on Claude Haiku built from one customer's 26 messages, January to October 2026. Each fact has two times: when it was true (across) and which event recorded it (up). A correction adds a band above and leaves the old answer below it, so you can ask both what was true on a date and what the store believed after any message. The page reads with a public key that can't commit. Event numbers count the store's commits; the agent committed once for each message with something to record, so 24 events came from 26 messages. Valid times follow the messages' dates, and the events were committed on 27 November 2026.

        
The customer and company are fictional. The store runs on one small server, so the page may be slow to answer.
